# Avatar data directory

Tracked directories contain prepared CC0-1.0 character metadata:

- `profiles/`: identity, speech, and personality summaries
- `arcs/`: narrative-position snapshots
- `logic/`: behavioral guidance extracted from a complete work

Untracked directories are created locally and can contain source or personal
data:

- `raw/`, `processed/`, `vectordb/`, `memory/`

See `../DATA_SOURCES.md`, `../docs/privacy.md`, and `provenance.json` before
adding or redistributing assets.
