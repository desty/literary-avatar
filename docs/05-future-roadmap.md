## Phase 3: 논문급 기능 — Novel Contributions

### 3.1 ⭐ 챕터별 캐릭터 아크 추적
> **연구 공백**: 기존 연구는 캐릭터를 정적 프로필로 취급

- 소설 타임라인에 따른 캐릭터 진화 모델링
- `agent.set_narrative_position(chapter=N)` — N장까지의 캐릭터로 대화
- 지식 상태, 감정 상태, 관계가 챕터별로 변화
- 스포일러 인식 대화

```python
# 예시: 홈즈가 "A Scandal in Bohemia" 전 vs 후
before = holmes.at_chapter(0)  # 아이린 애들러를 모름
after = holmes.at_chapter(1)   # "그 여자" — 유일하게 존경하는 여성
```

### 3.2 ⭐ 2차 Theory of Mind
> **연구 공백**: 캐릭터가 다른 캐릭터의 믿음을 추론하는 연구 없음

- 홈즈가 "왓슨이라면 이렇게 생각했을 것이다"라고 추론
- 사용자의 지식 수준을 추론하여 설명 깊이 조절
- 다른 캐릭터의 동기/의도에 대한 캐릭터 관점의 분석

```python
# 예시
user: "모리아티 교수에 대해 어떻게 생각하세요?"
holmes: "왓슨은 그를 단순한 범죄자로 볼 테지만,
         나는 그를 범죄의 나폴레옹이라 부르겠소.
         그의 수학적 두뇌가 범죄에 쓰이다니 참으로 유감이오."
```

### 3.3 ⭐ 텍스트→실행 가능한 캐릭터 로직 자동 추출
> **연구 공백**: 수동 명세가 아닌 자동 추출은 미개척 영역

- 소설 텍스트에서 "만약 X이면 캐릭터는 Y한다" 규칙을 자동 추출
- 확정적/확률적 분기를 포함하는 실행 가능한 로직
- Codified Character Logic (2025) 논문의 접근법을 자동화

### 3.4 독자 진행도 인식 시스템
- 사용자가 소설의 어디까지 읽었는지 추적
- 읽지 않은 부분에 대한 스포일러 방지
- "아직 그 이야기를 하기엔 이르오" 같은 캐릭터다운 회피

### 3.5 다축 평가 프레임워크
- CharacterBench 기반 자동 평가
- VER(Verifiable Emotion Reward) 적용
- 커스텀 메트릭: 캐릭터 아크 일관성, ToM 정확도
- 인간 평가 프로토콜 설계

**산출물**: 논문 초고 작성 가능한 수준의 시스템 + 실험 결과
